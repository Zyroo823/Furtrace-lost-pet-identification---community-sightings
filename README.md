FURTRACE

FURTRACE helps communities reunite missing pets with their owners using visual matching and community spotter reports.

Features

- Lost pet registration with photo uploads and facial feature analysis
- Community sighting reports with geographic privacy blur zones
- Dual panel image inspection comparing missing pet photos with sightings
- Guest account generation and local session management
- Map search with filters for species and date range

Technology Stack

- React 18
- TypeScript
- Tailwind CSS
- Vite

Getting Started

1. Install project dependencies using npm install.
2. Start local dev server using npm run dev.
3. Open your browser at http://localhost:3000.
